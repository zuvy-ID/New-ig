# 🎵 Music + Video Website

Website sederhana untuk GitHub Pages.

## Folder

- `assets/music/music.mp3` → ganti dengan lagu kamu
- `assets/video/video.mp4` → ganti dengan video kamu
- `index.html` → halaman utama
- `style.css` → tampilan/animasi
- `script.js` → fungsi tombol dan perpindahan halaman

## Cara pakai

1. Ganti `assets/music/music.mp3` dengan lagu kamu.
2. Ganti `assets/video/video.mp4` dengan video kamu.
3. Upload semua file ke repository GitHub.
4. Aktifkan GitHub Pages dari Settings → Pages.
5. Buka link GitHub Pages kamu.

## Alur

Buka website → Play Music → Start Video → Video berjalan dengan musik.

Jangan mengubah nama file `music.mp3` dan `video.mp4` kalau tidak ingin mengedit kode.
